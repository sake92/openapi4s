# OpenAPI4s

OpenAPI4s generates idiomatic Scala 3 models, HTTP server routes, clients, and
validators from OpenAPI 3.0/3.1 specifications. It also supports plain JSON
Schemas for model generation.

[![CI](https://github.com/sake92/openapi4s/actions/workflows/ci.yml/badge.svg)](https://github.com/sake92/openapi4s/actions/workflows/ci.yml)

- [Documentation](https://sake92.github.io/openapi4s)
- [Video demo](https://youtu.be/kf0vGrlKNb8)

Use OpenAPI4s through its [CLI](https://sake92.github.io/openapi4s/reference/cli.html)
or the build plugins for [sbt](https://github.com/sake92/sbt-openapi4s),
[Mill](https://github.com/sake92/mill-openapi4s), and
[Deder](https://github.com/sake92/deder-plugins/tree/main/deder-openapi4s).

For development and release instructions, see [DEV.md](DEV.md).
